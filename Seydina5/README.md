# 5th Grade Quest Academy

Open `index.html` in a modern browser. No installation is required.

## Features
- 5th grade prep modules for Math, Reading/ELA, Writing, Science, and Social Studies
- Progress tracker with XP, badges, streak, module progress, and quest dots
- Downloadable browser-generated progress report
- Audio narration using browser speech synthesis
- Interactive quizzes: multiple choice, true/false, and matching
- 20-minute focus timer and parent coaching script

## Recommended use
Use 4 short sprints per week. Each sprint should produce one visible artifact: a chart, drawing, paragraph, model, timeline, or problem solution.
