# Rising 7th Grade Quest Academy

Open `index.html` in a browser. No installation is required.

## What this package contains
- `index.html` interactive course launcher
- `styles.css` visual design and responsive layout
- `app.js` progress tracking, XP, badge, timer, and quiz logic
- `data/course_data.json` editable course content
- `assets/anime_learning_portals.png` course hero visual generated with Microsoft Copilot
- `docs/parent_guide.md` parent coaching guide
- `docs/source_map.md` source references used to build the course
- `docs/verification_report.md` checks performed

## Recommended use
Use 4 short sprints per week. Each sprint is 20 to 25 minutes. Pair every sprint with a visible artifact: a drawing, paragraph, number-line, map, table, or quick quiz.

## Personalization note
This version is intentionally visual, game-like, and low-clutter. It uses short missions, badges, focus timer, movement-break cues, and one-click external learning links.
